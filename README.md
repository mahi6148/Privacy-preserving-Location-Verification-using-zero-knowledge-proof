# This branch contains the code to run the Spring Boot application.

## instruction :
1. install rust.
2. compile the rust code acc to your os and architecture.
3. place the executable generated in the rust build folder to the springrustdll folder at the root directory.
4. now add that dll folder to your system environment variables.
5. for database i hosted my postgres server on docker.
6. read the applicationsecrets.txt and design.txt files to recreate the database setup and schema.
7. connect the database to the reserver and run the server
