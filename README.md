# This branch contains the code to run the Android application

## Instructions :
1. put the google services.json file and change web client id in the project.
2. install rust and build the rustbulletproofs folder using the instructions given in the secrets.txt file.
3. change the server ip in the string resources.xml file to your network hosted computer address, incase of connectivity exceptions check the port number and server ip address.
4. compile the project.
